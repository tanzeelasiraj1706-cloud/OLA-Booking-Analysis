# OLA-Booking-Analysis
OLA Booking Data Analysis using SQL and Power BI

# Project Overview

This project analyzes OLA booking data using SQL and Power BI to understand booking performance, customer activity, cancellations, revenue, and vehicle-type performance.

The project includes SQL based data analysis and an interactive Power BI dashboard to present the results in an easy 
to understand visual format.

## Project Objectives

- Analyze successful and cancelled bookings
- Identify customers with the highest number of rides
- Analyze customer and driver cancellations
- Compare booking value across different vehicle types
- Analyze revenue from successful bookings
- Understand booking trends over time
- Create an interactive Power BI dashboard
- Generate useful business insights from the booking data

## Tools Used

- PostgreSQL
- SQL
- Power BI

## Project Files

### 1. SQL Analysis
`SQL_OLA_Booking_Analysis.sql`

This file contains the SQL queries used to analyze the OLA booking dataset.

The analysis includes:

- Successful bookings
- Customer cancellations
- Top 5 customers by number of rides
- Driver cancellation reasons
- Average booking value by vehicle type
- Successful booking revenue by vehicle type
- Average booking value of successful rides
- Booking and revenue analysis

### 2. Power BI Dashboard
`dashboard powerbi.pbix`

The Power BI dashboard presents the analysis through interactive visualizations.

The dashboard includes:

- Overall Analysis
- Vehicle Type Analysis
- Revenue Analysis
- Cancellation Analysis
- Booking Status Trend
- Revenue by Vehicle Type

## Analysis Approach

The project follows these main steps:

**Data → SQL Analysis → Results → Power BI Visualization → Business Insights**

SQL was used to filter, group, count, and calculate values from the booking data. Power BI was then used to present the important results through charts, cards, tables, and dashboards.

## Key Business Insights

The analysis helps understand:

- Booking performance and booking status
- Customer ride activity
- Customer and driver cancellation patterns
- Revenue generated by different vehicle types
- Average booking value
- Overall booking trends

## Conclusion

The OLA booking analysis provides useful insights into ride bookings, revenue, cancellations, customer activity, and vehicle-type performance.

The combination of SQL and Power BI makes it easier to analyze the data and present business insights in a clear and interactive way.
